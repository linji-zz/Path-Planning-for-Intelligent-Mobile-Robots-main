# 耦合奖励与安全引导增强DQN实验总结

## 1. 实验代号定义

| 代号 | 完整含义 | 说明 |
|------|---------|------|
| S0 | 稀疏DQN基线 | 到达+10 / 碰撞-1 / 其他0，MLP网络 |
| S0A | 稀疏DQN + ASGS | 稀疏奖励 + 安全引导探索（alpha=0.1, lambda 5~15） |
| S0B | 稀疏DQN + ASGS调参 | alpha=0.5, lambda 2~6 |
| E0 | 原始距离DQN | (old_d - new_d) * 2.0 距离奖励 |
| E1 | 耦合奖励DQN | 距离 + 方向对齐 + 开阔度 |
| E1A | 耦合 + ASGS | E1 + 安全引导策略 |
| A1 | 耦合 - 开阔度 | 距离 + 方向对齐 |
| A2 | 耦合 - 方向对齐 | 距离 + 开阔度 |
| E2 | CAT + 耦合 | Cross-Attention Transformer + 耦合奖励 |
| N1 | MLP + 20%噪声训练 | 噪声对照：MLP |
| N2 | CAT + 20%噪声训练 | 噪声对照：CAT |

## 2. 核心实验（3个种子）

### 2.1 20x20地图

| 方法 | 训练SR (%) | 收敛轮数 | Best50奖励 | Greedy成功率 | 路径长度 |
|------|-----------|---------|-----------|-------------|---------|
| S0 | 80.7±2.6 | 7522±706 | 9.2±0.5 | 100% | 22-23 |
| E1 | 85.0±0.4 | 1561±128 | 107.8±0.6 | 100% | 22 |
| **E1A** | **97.7±0.8** | **926±45** | **114.2±4.0** | **100%** | **22** |

### 2.2 30x30地图

| 方法 | 训练SR (%) | 收敛轮数 | Best50奖励 | Greedy成功率 | 路径长度 |
|------|-----------|---------|-----------|-------------|---------|
| S0 | 46.8±34.4 | 7243±1600 | 6.0±4.2 | 66.7%（3次中1次失败） | 33-36 |
| E1 | 75.2±4.9 | 2766±530 | 137.1±5.0 | 100% | 33-35 |
| **E1A** | **96.8±0.5** | **3663±2528** | **206.4±45.7** | **100%** | **33-35** |

### 2.3 关键结论

1. **稳定性提升明显**：30x30上S0的训练SR标准差高达34.4%（含一次0%完全失败），E1降至4.9，E1A仅为0.5。
2. **E1A性能最优**：两张地图上训练SR均稳定达到96.5%-98.5%，Greedy测试成功率100%。
3. **ASGS不能单独使用**：稀疏奖励 + ASGS在30x30上失败（S0A/S0B），但与耦合奖励结合时效果最佳，验证两个改进互补。

## 4. 噪声鲁棒性

### 4.1 干净训练模型 + 噪声测试（200轮Greedy）

| 噪声 | MLP (E1) | CAT (E2) | 提升 |
|------|---------|---------|------|
| 0% | 100% | 100% | 0 |
| 5% | 80.5% | 90.5% | +10 |
| 10% | 47.0% | 62.5% | +15.5 |
| 15% | 19.0% | 43.0% | +24 |
| **20%** | **6.0%** | **30.0%** | **+24** |
| 30% | 0.0% | 6.0% | +6 |

结论：CAT凭借5步历史信息在20%噪声下较MLP提升24个百分点。

### 4.2 噪声训练模型 + 噪声测试

| 噪声 | MLP (N1) | CAT (N2) |
|------|---------|---------|
| 15% | 98.0% | 99.5% |
| 20% | 99.5% | 100% |
| 30% | 94.5% | 98.0% |

结论：噪声训练后两者成功率均较高，CAT在30%噪声下仍比MLP高3.5个百分点。

## 6. 创新点小结

1. **耦合奖励函数**：距离 + 方向对齐 + 开阔度三个信号耦合，提供趋近性、方向性、安全性引导。
2. **自适应安全引导策略（ASGS）**：安全加权探索 + 随训练进度增强的Q值软性惩罚。
3. **CAT-DQN**：双分支交叉注意力 + 5步历史信息，提升噪声环境感知鲁棒性。
